# Сировинні асети (не комітяться як є)

Сюди кладеться те, що ти генеруєш — я проганяю це скриптами в `public/assets`:

* `decor/<назва>.png` — декор на прозорому фоні (колодязь, трактор, опудало…);
* `walk/<вид>/001.png … 010.png` — кадри ходи (з AI-відео або від художника);
* `predators/<назва>.png` — кадри руху хижаків (підкрадається, тікає зі здобиччю);
* `map.png` — нова карта поля (пропорція 1.793, без прозорості).

Промпти для всього цього — у `docs/ART-PACK.md`.
