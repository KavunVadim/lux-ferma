# Контраст (WCAG 2.2 AA)

Таблиця нижче — не побажання, а результат перевірки. Кожна пара — фон і текст,
які реально існують у грі. Контраст рахується для **обох кінців градієнта**:
найгірший із двох і є значенням елемента.

Норма: **≥ 4.5** для звичайного тексту, **≥ 3.0** для великого (≥ 24px) і для
меж інтерфейсу.

## Кнопки (колір не залежить від теми)

| Елемент | Текст | Градієнт | Верх | Низ | Мін |
| --- | --- | --- | --- | --- | --- |
| `.btn--barn` «Кинути кубики» | `#ffffff` | `#b8473a → var(--barn-dark)` | 5.25 | 8.07 | **5.25** |
| `.btn--green` «Завершити хід» | `#ffffff` | `#3f7a30 → #2f6b2a` | 5.20 | 6.45 | **5.20** |
| `.btn--gold` «Готово» | `#2e2013` | `#f3c268 → var(--gold-dark)` | 9.55 | 6.63 | **6.63** |
| `.btn--wood` «Обмін» | `#ffffff` | `#8a5a33 → #66421f` | 5.85 | 8.88 | **5.85** |

`--barn-dark` у світлій темі `#8f2f26`, у темній `#c14f3d` — обидва дають ≥ 4.5
з білим текстом. `--gold-dark`: `#c78a2e` / `#d69e42` — обидва ≥ 5.3 з `#2e2013`.

## Базові токени

| Пара | Світла | Темна |
| --- | --- | --- |
| `--ink` на `--bg` | 14.23 | 14.68 |
| `--ink` на `--card` | 15.51 | 13.18 |
| `--ink-soft` на `--card` | 6.43 | 8.18 |
| білий на `--barn` | 5.72 | 3.30 |
| білий на `--leaf` | 4.71 | 2.38 |

Останні два рядки — причина, чому кнопки НЕ використовують `--leaf`/`--barn`
як фон під білим текстом: у темній темі ці токени світлішають під темні
поверхні, і контраст падає нижче норми.

## Правила для нових елементів

1. Не ставити текст кольором `var(--ink)` на «фарбовану» поверхню
   (кнопку, бейдж, вивіску) — `--ink` перемикається між темами.
2. Для кнопки задавати і фон, і колір тексту разом, у парі.
3. Рахувати контраст для **найгіршого кінця** градієнта, а не для середнього.
4. Перевіряти обидві теми — темна змінює і `--ink`, і частину фонів.
5. Світло-зелений `#a4d96b`-клас фонів не підходить ні під білий, ні під чорний
   текст на обох кінцях — для тексту поверх нього потрібен темніший фон.

Швидка перевірка в коді: `scripts/check-contrast.mjs` (див. `npm run check:contrast`).
